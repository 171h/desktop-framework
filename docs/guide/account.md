# 应用菜单与账户

## 应用菜单

标题栏左上角的大图标是应用菜单入口，取代了旧的「应用」文字按钮。菜单采用 AutoDesk 风格的全高面板，集中提供：

- 新建工作区、保存工作区、重置当前工作区布局；
- 打开欢迎页、命令面板与主题切换；
- 最近工作区切换；
- 框架文档、关于与退出应用。

应用菜单仍然使用命令注册表，新增入口时优先注册命令，而不是在菜单中直接编写业务逻辑。

## 本地账户

`account` 插件提供标题栏账户入口。未登录时显示「登录」按钮；登录后显示用户头像，点击头像打开账户管理菜单。

```ts
const user = ctx.account.login({
  name: '张三',
  email: 'zhang@example.com',
  password: 'secret1',
})

ctx.account.updateName('张三丰')
ctx.account.logout()
```

当前实现是本地演示账户：登录信息保存在本机 `ctx.storage` 中，密码只用于登录校验，不会持久化，也不会发送到网络。接入真实身份服务时，应将校验与令牌交换放到扩展宿主或后端，并使用受控消息契约更新 `AccountService`，不要把密钥放进渲染进程。
